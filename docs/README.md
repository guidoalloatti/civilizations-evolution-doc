## Regla de cambios

Registrar versión, estado, responsable, fecha y justificación. Etiquetar contenido como **Confirmado**, **Propuesto** o **Pendiente**. No resolver contradicciones mediante edición silenciosa; actualizar el registro de auditoría y el Maestro una vez tomada la decisión.
