# Documentation — Civilization Evolutions

The central design reference is the [GDD Maestro](00-project/GDD_MAESTRO.md). The specialized GDDs are the detail authority for each domain; the technical architecture is kept separate.

## Structure

- `00-project/`: GDD Maestro.
- `01-systems/`: GDDs for the game's systems.
- `02-technical/`: original technical plan, relocated without substantive changes.
- `../BACKUP_PRE_AUDIT_2026-11-03/`: complete copies of the 24 documents as they were before the reorganization.
- [Audit report](../AUDIT_REPORT.md): inventory, discrepancies, duplications, pending decisions and change log.

## Change rule

Record version, status, owner, date and rationale. Label content as **Confirmed**, **Proposed** or **Pending**. Do not resolve contradictions through silent editing; update the audit log and the Maestro once the decision is made.
